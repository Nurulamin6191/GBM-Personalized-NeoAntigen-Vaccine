# Workspace organization

Single publication folder (this repo). No wrappers, no duplicates.

```
GBM-Personalized-NeoAntigen-Vaccine/
├── README.md                  human-readable story + how to read the repo
├── 01_Data/                   SAMPLES.csv, WHY_DATASET.md, fetch.sh
├── 02_QC/                     trim reports (local runs) + run_qc.sh
├── 03_Alignment/              STAR/HISAT2 logs + flagstats + run_align.sh
├── 04_Variants/               counts, SDF4 evidence, dbSNP table + caller scripts
├── 05_HLA/                    OptiType rerun results + run_hla.sh
├── 06_Neoantigens/            candidate tables, Table 1/v2, validation CSVs + predictor scripts
├── 07_Figures/                fig01-10 + one generator script per figure
├── 08_Reproducibility/        config, env, methods, audit, validation, manifests, limitations
├── 09_Manuscript/             Report_Final.docx + manuscript_outline.md
├── CITATION.cff  LICENSE  .gitignore
```

## What syncs to GitHub
Everything above. Runtime dirs (`data-RUNTIME/`, `refs-RUNTIME/`, `results-RUNTIME/`,
`logs/`) are git-ignored and regenerated by the stage scripts in order 01→06.

## Removed during consolidation
Galaxy-Web-UI artifacts (FastQC HTMLs, Galaxy STAR logs, Ensembl-browser VEP PDFs,
prior-run HLA printouts, Project_Final-era PNGs), duplicate CSVs/HTMLs, superseded
preliminary stubs, submission zips, personal documents, 0-byte files. What remains
is either generated by a checked-in script or a small curated result with its
generating command documented in VALIDATION.md.
